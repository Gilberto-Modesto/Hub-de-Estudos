# Imagens do Hub de Estudos

Esta pasta centraliza as imagens do projeto.

- `logo-hub-estudos.png` — logo principal.
- `favicon-16x16.png` e `favicon-32x32.png` — ícones do navegador.
- `apple-touch-icon.png` — ícone para dispositivos Apple.
- `icon-192.png` e `icon-512.png` — ícones para futuras versões/PWA.

Para adicionar novas imagens, coloque-as nesta pasta e use caminhos como:
`assets/img/nome-da-imagem.png`
